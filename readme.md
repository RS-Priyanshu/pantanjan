## 🌟 Project Overview

This project was commissioned to translate the client's organizational goals, spiritual heritage, community welfare programs, and visitor resources into a coherent, modern, and mobile-friendly web experience.

The primary goal was to bridge the organization's community work with an accessible public interface where visitors can:
- Learn about the trust's identity and foundational values.
- Explore humanitarian and community-care initiatives.
- Access educational resources, event galleries, and Islamic calendar schedules.
- Connect directly with representatives or find pathways for volunteering.

## 💻 Website Features

### 1. Home & Organization Introduction
The primary landing area presenting the identity, mission statement, location context, and core message of the Darbar-e-Panjatan Paak Trust.

### 2. Spiritual Compass
Educational, curated content focusing on spiritual context and religious tradition, providing visitors with a reflective background.

### 3. Vision, Mission & Values
Articulates foundational principles, centering on public service, compassionate action, equity, and mutual support.

### 4. Community Initiatives Directory
A categorized portfolio presenting the Trust's active and stated humanitarian initiatives across food security, healthcare, and education.

### 5. Governance & Transparency
Dedicated information section highlighting stated accountability, administrative stewardship, and governance principles.

### 6. Get Involved & Volunteering
A participatory gateway providing community members and visitors with avenues for volunteering, collaboration, and direct participation.

### 7. Media Gallery
Visual documentation showcasing community gatherings, seasonal distributions, and historical events.

### 8. Islamic Calendar Resource
Integrated access to Islamic calendar dates, aiding visitors in tracking observances and community schedules.

### 9. Contact & Location Hub
Transparent directory detailing official communication channels, inquiry options, and geographical location resources.

### 10. Smooth Section Navigation
Cohesive, fast in-page and cross-page navigation allowing visitors to move naturally through the site's various sections.

## ⚙️ Local Setup & Development

Follow these steps to run or examine the source code locally:

### Prerequisites
- [Git](https://git-scm.com/)
- A modern web browser (Google Chrome, Firefox, Safari, Edge)
- Visual Studio Code or your preferred code editor
- *(Optional)* Node.js & npm (if using local tooling/bundlers)

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

### 2. Run locally
- **Static setup (HTML/CSS/JS):**
  Open `index.html` directly in your browser, or serve it using Python:
  ```bash
  python -m http.server 8000
  ```
  Then visit `http://localhost:8000` in your web browser.

- **Node/NPM project (if using build tools):**
  ```bash
  npm install
  npm run dev
  ```
